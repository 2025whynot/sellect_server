# 🚀 Sellect

## 📌 프로젝트 개요

대규모 트래픽을 고려한 이커머스 플랫폼의 핵심적인 요구사항을 파악하고, 안정적이고 원활한 운영을 위한 대응전략 마련

- **📅 기간**: 2025.02.01 ~ 2025.04.03
- **🛠 기술 스택**: Java, Spring Boot, MySQL, Redis, Kafka
